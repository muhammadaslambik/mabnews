# MAB-News + CMS

Prototype tahap 1: Homepage portal berita berdasarkan ilustrasi desain yang diberikan.

## Struktur
- `index.html` — Homepage
- `css/` — CSS portal
- `js/` — JavaScript portal dan API
- `admin/` — CMS (placeholder tahap awal)
- `admin-css/` — CSS CMS
- `admin-js/` — JavaScript CMS
- `assets/images/` — aset gambar homepage

## Menjalankan
Bisa langsung dibuka dengan `index.html`, atau gunakan GitHub Pages setelah repository dipush.

## Catatan
Gambar pada prototype tahap ini berasal dari crop ilustrasi referensi yang diberikan untuk menjaga kemiripan visual. Pada tahap produksi, gambar berita sebaiknya diganti dengan aset berita asli dari CMS/API.
